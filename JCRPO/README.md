## Описание проекта
«Калькулятор Жизни» — это десктопное приложение с графическим интерфейсом, разработанное на языке C++ с использованием библиотеки Qt. 

Программа по введенной дате рождения вычисляет статистические показатели прожитой жизни человека, основываясь на усредненных научных данных:
- количество проспанного времени (в часах и сутках);
- общее количество морганий;
- количество ударов сердца;
- объем перекачанной сердцем крови (в литрах);
- объем выпитой воды (в литрах);
- количество раз смеха.

Приложение реализовано с использованием архитектурного паттерна MVC (Model-View-Controller) с активной моделью, которая самостоятельно уведомляет представление об изменении данных через паттерн «Наблюдатель». В программе предусмотрена строгая валидация вводимых данных с выводом понятных сообщений об ошибках, а также функция запоминания и автоматического восстановления последних введенных значений при повторном открытии окна ввода.
